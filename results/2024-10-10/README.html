We only have samples with data from Langfjordvatn and Suopatjavri. Most of them come from L fish, and only two from P fish. Thus, there is no point in attempting an estimation of \(F_{ST}\) between the two ecomorphs. If anything, we can estimate \(F_{ST}\)s between lakes and between sexes. Dates of collection and dissection are very evenly distributed along september, 2017.

Considering results in 2024-10-05, we have two putative species, one predominating in each lake. Thus, the comparison between lakes must also be a comparison between putative species.

From the whole-genome SAF files, I generate below the SFS for a visualization and comparison among populations. We don’t really need individual SFS for \(F_{ST}\) calculation, but we need it for other purposes. This is run in Garnatxa as well, with the same script.

if [ ! -d SFS ]; then mkdir SFS; fi
for pop in $(ls -1 *.list); do
   NAME=$(basename -s .list $pop)
   if [ ! -e SFS/$NAME.sfs ]; then
      realSFS -fold 1 \
              -nSites 5000000 \
              SAF/$NAME.saf.idx 1> SFS/$NAME.sfs 2> SFS/$NAME.log
   fi
   # If the EM optimization is repeated, due to instability detected,
   # more than one SFS is output, in different lines. We need to keep
   # only the last one.
   if [ $(cat SFS/$NAME.sfs | wc -l) -gt 1 ]; then
      mv SFS/$NAME.sfs SFS/$NAME.sfs_multiple
      tail -n 1 SFS/$NAME.sfs_multiple > SFS/$NAME.sfs
   fi
done
