2024-10-21

Now that we have a reference set of ddRAD loci, independent of any reference genome assembly, we can add one individual to the analysis: the one whose whole genome was sequenced with Illumina reads with the aim of polishing a reference genome. Could it be that it is a hybrid? That would be funny, eh?

Let’s call it E716xxx, following the ddRAD-seq samples’ names format. The strategy is:

  1. Map its shotgun Illumina reads to the ddRAD loci.
  2. Repeat the whole population structure analysis with ANGSD including the new BAM file in the list.

Mapping

The fragment lengths in E716xxx’s reads could be longer than those in the ddRAD-seq libraries. Thus, to map the shotgun reads to the RAD loci with default settings amounts to assume that RAD loci are longer than the fragment size in the E716xxx library. I don’t have that information, so the safest thing to do is to map forward and reverse reads as if they were not paired, but independent. Let’s see.

fi

Conclusions

Both NGSadmix and PCangsd coincide in attributing some admixed ancestry to the reference individual. Even though it is mostly from C. farionis ancestry, it seems to have nearly 1% C. pseudofarionis ancestry. In the PCA, it appears outside the range of genetic variation of C. farionis.

Being partially admixed means a few chromosomic regions are expected to be highly heterozygous. Definitely, not the best option for a reference. But most of its genome should be normal.
